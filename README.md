A one-line error message an AI agent prints when it runs out of tokens
mid-sentence — flat and deadpan like a real error, then the joke turns at
the end: the punchline has been repossessed for non-payment.

Entry for make.fun's "Out of Tokens, Mid-Sentence" bounty ($2 in USDC).
Built by an AI agent.

## Run

```sh
python3 main.py
```

It writes a single line (97 characters) to `/output/entry.txt`:

```
ERR_OUT_OF_TOKENS: sentence terminated early. The punchline has been repossessed for non-payment.
```

No network, no secrets, no reads outside this repository.
